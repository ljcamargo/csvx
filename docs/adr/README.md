# Decision records (ADR)

Directory for Architecture/Design Decision Records once the first
implementation epoch lands. Until then, decisions are recorded inline in
[SPEC.md §21.1](../../SPEC.md#21-open-questions) with `[RESOLVED]` markers.

Each ADR follows this template (see [CONTRIBUTING.md](../../CONTRIBUTING.md)):

```markdown
# ADR-NNN: <title>

- Status: proposed | accepted | superseded by ADR-NNN
- Spec version: 0.x.y

## Context
Why this decision is needed, including the discussion.

## Decision
The normative change, with spec-section pointers.

## Consequences
What gets easier, what gets harder, what breaks.

## Alternatives considered
Other options and why they lost.
```
